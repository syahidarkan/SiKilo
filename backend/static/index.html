🔬 NILM Detector

Non-Intrusive Load Monitoring — AI memecah konsumsi energi per mesin dari 1 sensor induk.

Cara Kerja NILM

1. Event Detection (CUSUM)
Sensor mendeteksi transien daya |ΔP| ≥ 50W dalam jendela 3 detik menggunakan algoritma CUSUM sliding-window.


2. Feature Extraction
Setiap event diekstrak menjadi vektor 7 dimensi:
[ΔP, ΔQ, Q/P ratio, V_rms, Inrush_Peak, Hour, DayOfWeek]


3. LightGBM Classifier
Model gradient boosting mengklasifikasikan event ke 6 kelas mesin. Jika model belum dilatih, fallback ke rule-based heuristic.


4. Ground Truth Loop
Smart plug Tuya/Tasmota dipasang 7 hari pertama untuk fine-tuning model per UMKM.
